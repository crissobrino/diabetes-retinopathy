CELL 26 — FILLED IN (was cell 25 placeholder)
-----------------------------------------------
Implemented three torchvision-backed transform classes following the TVCenterCrop pattern
(numpy -> PIL -> torchvision op -> numpy):

  TVRandomHorizontalFlip(p=0.5)
    Why: fundus images from left/right eyes are mirror-symmetric; horizontal flip
    simulates this real-world variation.

  TVRandomRotation(degrees=15)
    Why: fundus cameras are sometimes slightly tilted; small rotations simulate
    real-world acquisition variation.

  TVColorJitter(brightness=0.3, contrast=0.3, saturation=0.2, hue=0.05)
    Why: fundus cameras across clinical sites differ in exposure, lighting, and
    calibration; colour jitter simulates these cross-site variations.

CELL 37 — FILLED IN (was cell 36 placeholder)
-----------------------------------------------
Completed the CustomNet architecture. Filled in all placeholder '...' values:

  conv1: Conv2d(3, 6, 5)   + BatchNorm2d(6)
  conv2: Conv2d(6, 16, 5)  + BatchNorm2d(16)
  conv3: Conv2d(16, 32, 5) + BatchNorm2d(32)
  conv4: Conv2d(32, 64, 5) + BatchNorm2d(64)
  pool:  MaxPool2d(2, 2)   (shared across all conv blocks)

  Spatial dimension math (Conv5 no-padding + MaxPool2):
    224 -> 220 -> 110  (conv1 + pool)
    110 -> 106 ->  53  (conv2 + pool)
     53 ->  49 ->  24  (conv3 + pool)
     24 ->  20 ->  10  (conv4 + pool)
  Flattened: 64 * 10 * 10 = 6400

  fc1: Linear(6400, 120)
  fc2: Linear(120, 84)
  dropout: Dropout(0.5)   <- added before output for regularisation
  fc3: Linear(84, 1)      <- single logit output, no sigmoid (see cell 43)

  forward() returns raw logits. Sigmoid is applied by BCEWithLogitsLoss during
  training and by test_model/eval_val_auc during inference.

  BatchNorm2d after each conv layer stabilises training on small datasets.
  Dropout(0.5) before fc3 reduces overfitting on 2000 training images.


CELL 43 — MODIFIED (was cell 42)
----------------------------------
Two changes:
  1. Replaced nn.BCELoss() with nn.BCEWithLogitsLoss(pos_weight=pos_weight).
     Reason: the dataset is severely imbalanced (1468 No-DR vs 532 DR, ~73%/27%).
     Without weighting the network learns to predict "No DR" for everything and
     achieves near-zero BCE loss with AUC ~0.5.
     pos_weight = 1468/532 ≈ 2.76 is computed dynamically from train_dataset.
     BCEWithLogitsLoss also applies sigmoid internally, so the network's forward()
     must return raw logits (enforced by the CustomNet change above).

  2. This criterion is shared by both CustomNet and fine-tuning training.


CELL 45 — MODIFIED (was cell 44)
----------------------------------
Three changes to train_model():
  1. Fixed sigmoid/loss coupling: removed F.sigmoid(outputs.flatten()) before the
     loss call. Now:
       logits = model(inputs).flatten()
       loss   = criterion(logits, labels)       # BCEWithLogitsLoss, sigmoid internal
       scores = torch.sigmoid(logits).detach()  # for AUC computation only
     This prevents double-sigmoid (dead gradients) and NaN loss from applying BCE
     to already-sigmoided values.

  2. Added patience-based early stopping (default patience=7).
     If val AUC does not improve for `patience` consecutive epochs the loop breaks
     early, loads the best weights, and returns. This prevents wasteful computation
     on long training runs.

  3. Minor: stores per-batch scores correctly from the separated `scores` variable.


CELL 49 — MODIFIED (was cell 48)
----------------------------------
Changed num_epochs=10 -> num_epochs=30, patience=7.
10 epochs is insufficient for a CNN training from random initialisation on 2000 images.
With StepLR(step_size=10, gamma=0.1) there are two LR drops (at epochs 10 and 20),
giving the network time to converge. Early stopping will exit early if needed.


CELL 53 — MODIFIED (was cell 52)
----------------------------------
Three changes:
  1. Replaced deprecated models.alexnet(pretrained=True) with:
       from torchvision.models import resnet18, ResNet18_Weights
       ftNet = resnet18(weights=ResNet18_Weights.IMAGENET1K_V1)
     pretrained=True raises UserWarning / TypeError in torchvision >= 0.13.

  2. Switched backbone from AlexNet to ResNet18.
     ResNet18 has better ImageNet performance (69.8% vs 56.5% top-1) and uses
     residual connections, which makes fine-tuning more stable.

  3. Added layer-freezing strategy:
       - Freeze entire backbone first
       - Unfreeze layer3, layer4 (deep semantic features benefit from adaptation)
       - New ftNet.fc = Linear(512, 1) is unfrozen by default
     This is better than full fine-tuning on 2000 images as it prevents overfitting
     the early convolutional features.
     Also added a print showing trainable vs total parameter counts.

Changes vs sixth_attempt:
- (C-1) Squeeze-and-Excitation (SE) blocks added to CustomNetV2.
  SEBlock (Hu et al., 2017): GAP each channel -> bottleneck MLP
  (reduction=16) -> Sigmoid -> channel-wise rescale.
  Applied to blocks 3, 4, 5 (128, 256, 256 channels).
  Blocks 1-2 (32, 64 ch) unchanged (low-level texture features
  do not benefit from channel attention at this scale).
  Saves best_customnetv2_se.pth.

- Fine-tuning category: DenseNet121 unchanged from sixth_attempt
  (Stage 1: denseblock4+norm5; Stage 2: denseblock3+transition3;
   warmup + CosineAnnealingLR; label_smoothing=0.05).

Results: val AUC custom 0.72 (vs 0.786 in sixth_attempt).
         Fine-tuning AUC unchanged (same DenseNet121 pipeline).

Analysis:
  SE blocks increased CustomNetV2 parameter count and added channel
  attention capacity, but the 2000-image training set is too small
  to learn meaningful channel weights without overfitting. The SE
  excitation MLP sees the same limited diversity of fundus images
  as the conv layers, so it cannot learn to suppress background
  channels more reliably than BatchNorm alone. The val AUC drop of
  ~0.066 vs sixth_attempt confirms overfitting, not underfitting.
  SE blocks are beneficial in large-scale medical imaging benchmarks
  (e.g. SE-ResNet on CheXpert) where the dataset is large enough
  to train the excitation weights. On this dataset, the baseline
  5-block CNN with GAP and Dropout regularisation is more effective.

Decision: SE variant not submitted. Experiments C-2 onward explore
  alternative FT backbones rather than modifying CustomNetV2 further.

Edits by Maria — 02/04
=======================
Filled in the course-provided starter notebook (notebooks/archive/starter/starter_template.ipynb).

- Fixed DATA_ROOT: notebook assumed a ./data/ subfolder; CSVs and images/ are actually at the project root.
- Implemented TVRandomHorizontalFlip, TVRandomRotation(15deg), TVColorJitter (torchvision-backed transform classes, following the given TVCenterCrop pattern).
- Wired the three transforms into the training pipeline: CropByEye -> Rescale(256) -> flip -> rotate -> jitter -> RandomCrop(224) -> ToTensor -> Normalize. Val/test stays deterministic.
- Set maxSize=0 (was 500) to train on all 2000 images.
- Set num_workers=0 on all DataLoaders (PyTorch multiprocessing hangs on Windows).
- Filled in CustomNet: Conv(3->6->16->32->64, 5x5) + BatchNorm each block, MaxPool2d shared, FC head 6400->120->84->1, Dropout(0.5) before output.
- Switched BCELoss -> BCEWithLogitsLoss(pos_weight=n_neg/n_pos ~2.76): dataset is 73%/27% imbalanced; unweighted loss collapses to predicting the majority class.
- Fixed train_model(): removed a manual sigmoid before the loss call (was double-applying sigmoid with BCEWithLogitsLoss, causing dead gradients). Added patience-based early stopping.
- Replaced deprecated AlexNet(pretrained=True) with ResNet18 (ImageNet1k weights); froze the backbone except layer3/layer4 + new fc head.
- Added eval_val_auc() to sanity-check both models on the labeled validation set before submitting to Codabench.

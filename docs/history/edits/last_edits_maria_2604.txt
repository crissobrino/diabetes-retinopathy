SEVENTH ATTEMPT  (J-series)
----------------------------
Key change: Introduced SE-CustomNetV2 (channel attention via Squeeze-and-Excitation blocks,
reduction ratio r=8 added after every Conv-BN-ReLU block). Trained two independent seeds
(42, 123) of SE-CustomNetV2 and took the uniform mean ensemble.

Also tested 8-pass TTA (adding rot90 variants) — it hurt both custom and FT models vs
4-pass TTA. Reverted to 4-pass: original + hflip + vflip + rot180.

Also tried DenseNet Stage 3 unfreeze (denseblock2+transition2) on the FT model — it
overfitted and AUC dropped from 0.781 to 0.768. Stage 3 unfreeze abandoned.

Results (public / private):
  Custom (SE-V2 2-seed):  0.756 / 0.762
  FT (DenseNet121 S1+S2): 0.768 / 0.754


EIGHTH ATTEMPT  (K-series)
---------------------------
Key change: Two-architecture ensemble — SE-CustomNetV2 (seed=42) + CustomNetV3 (new).
CustomNetV3 introduced residual skip connections (ResBlock = Conv3x3-BN + 1x1 projection
skip -> ReLU -> MaxPool), same channel progression as V2 (3->32->64->128->256->256).
Approximately 1.05M parameters. Uniform mean of the two model outputs.

Also: fixed cudnn flags (deterministic=True, benchmark=False) for full reproducibility.

FT model for this attempt was trained by cris (attempt_22): ResNet50 Stage 1+2 with
IMAGENET1K_V2 weights. Stage 1 unfreezes layer4, Stage 2 unfreezes layer3.

Results (public / private):

  FT (attempt_22, cris):  0.780 / 0.791

TENTH ATTEMPT  (M-series)
--------------------------
Key change: Four-architecture ensemble with a single seed (42). Architectures:
  - CustomNetV2 (plain, no attention, no skip)
  - SE-CustomNetV2 (channel attention, no skip)
  - CustomNetV3 (residual skip, no attention)
  - SECustomNetV3 (NEW: residual skip + SE channel attention, ~1.09M params)

SECustomNetV3 combines the SE attention mechanism from SE-V2 with the residual blocks
from V3 (SEResBlock = Conv3x3-BN + 1x1-skip -> ReLU -> SEBlock(r=8) -> MaxPool).

Ensemble is a uniform arithmetic mean of the four model sigmoid outputs (TTA-4 each).

FT model for this attempt was trained by cris (attempt_24): loads the 5 backbone
checkpoints from attempt_23 without retraining, performs a val-set grid search over
ensemble weights (weighted mean instead of uniform), same 380px / ±180° setup.
This is the best FT result overall.

Per-model val AUC (TTA-4) during training:
  v2:    0.7788
  se_v2: 0.5241  (catastrophic failure — failed to converge, effectively random)
  v3:    0.7688
  se_v3: 0.7711
  4-model uniform ensemble val AUC: 0.7837

Note: se_v2 failing dragged the ensemble down. The 4-model mean includes a near-random
component, which adds noise rather than signal.

Results (public / private):
  Custom (4-arch ensemble): 0.760 / 0.773
  FT (attempt_24, cris):    0.835 / 0.826   <-- best FT result overall

TWELFTH ATTEMPT  (N2-series, not yet run)
------------------------------------------
Motivation: cris's fine-tuning jump from 0.806 to 0.835 came almost entirely from two
changes — 380px input resolution and expanding rotation from 15° to ±180°. The same
changes have never been applied to the custom models. Fundus images have no canonical
orientation (camera can be held at any angle), so ±180° rotation is the correct prior.
Higher resolution preserves fine vessel detail that gets lost at 224px.

Base: ninth_attempt (3-seed CustomNetV2, which had the best private AUC of 0.780).
Architecture: CustomNetV2 unchanged (GAP makes it resolution-agnostic; no code changes
needed to handle larger input).

Changes vs ninth_attempt:
  Rescale:           256  ->  416
  RandomCrop (train): 224  ->  380
  CenterCrop (eval):  224  ->  380
  TVRandomRotation:    15° -> 180°
  Train batch size:    64  ->  32   (larger feature maps; fits safely on Kaggle T4/P100)
  Val/test batch size: 256 ->  128

Everything else identical: seeds 42/123/456, AdamW(lr=1e-3, wd=5e-3),
CosineAnnealingLR(T_max=50), patience=10, BCEWithLogitsLoss(pos_weight~2.759),
WeightedRandomSampler, TVRandomHFlip+VFlip+ColorJitter, 4-pass TTA.

Expected training time: ~90 minutes total on Kaggle T4 (3 seeds x ~30 min each).
Target: val ensemble AUC (TTA-4) above ninth_attempt's 0.757 public / 0.780 private.

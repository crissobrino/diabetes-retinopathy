9. fourth_attempt.ipynb — Experiments H-1, H-2, H-3: BenGraham + 4-pass TTA + label smoothing

Changes vs second_attempt_tuned:
- (H-1) BenGraham(sigmaX=10) preprocessing inserted after CropByEye in both
  train and val/test pipelines
- (H-2) 4-pass TTA: original + hflip + vflip + rot180 (up from 2-pass hflip)
- (H-3) Label smoothing eps=0.05 for EfficientNet training only

Motivation for H-1:
  Ben Graham's local contrast normalisation (Kaggle DR 2015 winner) subtracts
  a Gaussian-blurred background from each image to enhance microaneurysms,
  exudates, and fine vessel structure. Formula:
    enhanced = 4 * image - 4 * GaussianBlur(image, sigmaX=10) + 128
  This highlights high-frequency detail relative to the local mean, which is
  especially useful for detecting small DR lesions.

Motivation for H-2:
  2-pass TTA only covers horizontal reflection. Adding vertical flip and 180°
  rotation increases inference diversity without introducing distribution shift,
  since fundus images are approximately radially symmetric (no strong up/down
  prior, unlike natural images).

Motivation for H-3:
  Reused from third_attempt G-2. EfficientNet reaches train AUC ~0.97 at the
  best checkpoint; label smoothing prevents over-confident logits on memorised
  training examples. Not applied to CustomNetV2 (not overfitting).

THE BUG (H-1):
  The BenGraham implementation assumed float32 [0,1] input but CropByEye
  returns the raw output of skimage io.imread(), which is uint8 [0,255].
  The buggy code path:

    img_u8 = (np.clip(image, 0, 1) * 255).astype(np.uint8)

  np.clip(uint8_array, 0, 1) clamps every non-zero pixel to 1 and every
  zero pixel to 0. Multiplying by 255 gives a binary {0, 255} array.
  GaussianBlur of an all-{0,255} image blurs to ~255 everywhere (for a
  non-black eye image). Then:

    addWeighted(img_u8=255, alpha=4, blurred=255, beta=-4, gamma=128)
    = 4*255 - 4*255 + 128 = 128

  Every pixel of every image was mapped to neutral gray 128. The model
  was trained on a dataset of 2000 identical gray rectangles.

  No sanity-check cell existed in fourth_attempt, so the bug was not
  caught before training. Training loss converged normally (the model
  learned a constant-output function), and val AUC appeared to be computed
  but reflected random performance.

Results: custom AUC 0.541 / 0.557, ft AUC 0.558 / 0.533 (public / private)
Worst scores of any experiment across all models. Near-random performance on
both categories. The collapse is worse than the CLAHE disaster (attempt_with_a_b)
because CLAHE at least preserved some image information; here every image was
identical gray.

Post-mortem:
  H-2 (4-pass TTA) and H-3 (label smoothing) cannot be evaluated from this
  experiment — any effects are masked by the complete image destruction from H-1.
  The three changes need to be re-tested in fifth_attempt with the dtype bug fixed.

Changes vs second_attempt_tuned (i.e. fourth_attempt with H-1 bug fixed):

Change H-1 (fixed): BenGraham local contrast normalisation

  Fix 1 — dtype guard:
    if image.dtype == np.uint8:
        img_u8 = image
    else:
        img_u8 = (np.clip(image, 0, 1) * 255).astype(np.uint8)

  When CropByEye passes uint8 [0,255] (the standard case), img_u8 is assigned
  directly without any clipping or rescaling. The float path is kept as a
  fallback for any caller that passes a pre-normalised array.

  Fix 2 — circular background mask:
    mask = np.zeros(enhanced.shape, dtype=np.uint8)
    cv2.circle(mask, (w//2, h//2), int(0.9 * min(h, w) / 2), (1,1,1), -1)
    enhanced = enhanced * mask + 128 * (1 - mask)

  After addWeighted, pixels outside a circle of radius 0.9*min(h,w)/2
  centred on the image are set to neutral gray 128. This prevents the
  contrast-enhancement formula from amplifying noise at the image border
  (where the black background meets the eye boundary).

  Output: float32 / 255.0 — BenGraham returns float [0,1] so the rest of
  the pipeline (Rescale, CenterCrop/RandomCrop, ToTensor, Normalize) is
  unchanged.

  Applied in both the training pipeline (after CropByEye, before Rescale)
  and the val/test pipeline (after CropByEye, before Rescale).

Sanity-check cell (new):
  Runs a single sample through the full training pipeline and asserts that
  the normalised output mean is not near 0.5:

    assert abs(_img.mean()) < 0.3, "BenGraham all-gray bug still active!"

  A uniform gray 128 image normalised with ImageNet stats produces a mean
  close to 0.5 per channel. The assertion fires exactly when the fourth_attempt
  bug is present, catching the failure before any training begins.

Change H-2: 4-pass TTA (unchanged from fourth_attempt)
  eval_val_auc() and test_model() updated to support tta=True (4-pass).
  Four forward passes per image: original, hflip, vflip, rot180.
  Score = mean of sigmoid outputs across all four passes.
  EfficientNet uses TTA at both val (for Stage 2 threshold check) and test.
  CustomNetV2 uses TTA at val (for ensemble threshold) and test.

  Note on vflip for EfficientNet: vertical flip at inference only (not training)
  is acceptable because the ImageNet upright prior only constrains the training
  distribution, not the inference ensemble. The risk of adding vflip to
  inference TTA is low because fundus images have no strong vertical orientation.

Change H-3: Label smoothing eps=0.05 for EfficientNet (unchanged from fourth_attempt)
  train_model() accepts label_smoothing=0.05 for EfficientNet Stage 1 and Stage 2.
  CustomNetV2 keeps label_smoothing=0.0 (default).
  Formula: labels_for_loss = labels * 0.95 + 0.025
  Hard targets {0, 1} become soft targets {0.025, 0.975}.

All other components identical to second_attempt_tuned:
  - CustomNetV2 architecture, AdamW lr=1e-3 wd=5e-3, CosineAnnealingLR(T_max=50),
    50 epochs, patience=10
  - EfficientNet-B0 Stage 1: AdamW lr=3e-4 wd=1e-2, T_max=30, 30 epochs, patience=7
  - EfficientNet-B0 Stage 2: unfreezes features[5], lr=3e-5, T_max=15, 15 epochs,
    patience=5; only runs if Stage 1+TTA val AUC >= 0.752; reverts if AUC regresses
  - WeightedRandomSampler (batch size 64 train, 256 val/test)
  - Ensemble grid search w in {0.10...0.30}; skipped if custom val AUC <= 0.62

Results: custom AUC 0.770 / 0.770, ft AUC 0.757 / 0.755 (public / private)

Analysis:
  CustomNetV2: public +0.004 vs second_attempt_tuned (0.770 vs 0.766), but private
  +0.027 (0.770 vs 0.743). The private uplift is unusually large and suggests that
  BenGraham local contrast generalises better to the held-out test distribution —
  consistent with the original motivation (enhancing lesion structure reduces
  reliance on low-level illumination cues that vary across imaging devices).

  EfficientNet: public -0.013 vs second_attempt_tuned (0.757 vs 0.770), private
  +0.011 (0.755 vs 0.744). The public regression is unexpected given the private
  improvement; it may reflect the EfficientNet Stage 2 threshold not being met
  in this run, or that 4-pass TTA adds more variance for the fine-tuned model
  (which already had strong 2-pass TTA performance).

  H-2 and H-3 in isolation cannot be attributed from this experiment because all
  three changes are applied together. The private AUC jump strongly implicates
  BenGraham as the primary driver for CustomNetV2.

%% ── 1. INTRODUCTION ──────────────────────────────────────────────
\section{Introduction}

Diabetic Retinopathy (DR) is a leading cause of preventable blindness.
This work develops a binary DR/No-DR classifier from fundus photographs
across two competition tracks: a \emph{custom} CNN trained from scratch
(CUSTOM) and a \emph{fine-tuned} pretrained backbone (FINE-TUNING).
Performance is measured by AUC on a held-out 1\,000-image test set
evaluated via Codabench.

%% ── 2. DATASET & PREPROCESSING ──────────────────────────────────
\section{Dataset \& Preprocessing}

The dataset contains 2\,000 training / 500 validation / 1\,000 test fundus
images with a severe class imbalance (73\% No-DR, 27\% DR). Right-eye
images are horizontally mirrored to unify anatomical orientation.

\textbf{Pipeline.}
\texttt{CropByEye} crops the visible retinal disc via intensity thresholding.
BenGraham local contrast normalisation~\cite{graham2015kaggle} (sigmaX=10,
circular background mask) then enhances microaneurysms and vessel structure.
Images are rescaled to 256\,px; training augmentations add random horizontal
flip, rotation ($\pm$15°), colour jitter, and a random 224\,px crop.
Validation uses a centre crop. All images are ImageNet-normalised
($\mu$=[0.485,\,0.456,\,0.406]; $\sigma$=[0.229,\,0.224,\,0.225]).

%% ── 3. CUSTOM MODEL ──────────────────────────────────────────────
\section{Custom Model (CUSTOM)}

\subsection{Baseline: CustomNet}
A 4-block CNN with 5$\times$5 no-padding convolutions
(3→6→16→32→64), BatchNorm and MaxPool per block, flattened to 6\,400-d,
and head 6400→120→84→\texttt{Dropout}(0.5)→1. SGD + StepLR; AUC\,=\,0.570.

\subsection{CustomNetV2}
To improve generalisation on the small training set:
\begin{itemize}
  \item \textbf{5 blocks, 3$\times$3 same-padding} convolutions
        (3→32→64→128→256→256), reducing spatial size with MaxPool per block.
  \item \textbf{Global Average Pooling} replaces the 6\,400-d flatten,
        giving translation invariance and a compact 256-d representation.
  \item \textbf{Head}: \texttt{Dropout}(0.2)→Linear(256,128)→ReLU→
        \texttt{Dropout}(0.4)→Linear(128,1).
  \item \textbf{Optimiser}: AdamW (lr=1e-3, wd=5e-3),
        CosineAnnealingLR ($T_\text{max}$=50), 50\,epochs, patience=10.
\end{itemize}
Adding \texttt{WeightedRandomSampler} raises public AUC to 0.766; with
BenGraham preprocessing and 4-pass TTA the final best is \textbf{0.786}.

%% ── 4. FINE-TUNING MODEL ─────────────────────────────────────────
\section{Fine-tuning Model (FINE-TUNING)}

ResNet18~\cite{he2016deep} (0.698) was superseded by
\textbf{EfficientNet-B0}~\cite{tan2019efficientnet} with two-stage
progressive unfreezing (\texttt{features[6--8]}, then \texttt{features[5]};
AdamW lr=3e-4, $T_\text{max}$=30, label smoothing), reaching 0.770.
However, severe overfitting persists: train AUC 0.919 vs.\ val 0.785 at best
checkpoint (gap 0.134, Fig.\,\ref{fig:curves}).

\textbf{DenseNet121}~\cite{huang2017densely} — dense connections reuse
features from all preceding layers within each block, providing implicit
regularisation on 2\,000 images (standard backbone for medical imaging).
Head: \texttt{Dropout}(0.5)→Linear(1024,1).
\emph{Stage\,1}: \texttt{denseblock4\,+\,norm5} ($\approx$2.16\,M trainable),
AdamW lr=3e-4, $T_\text{max}$=30, patience=7.
\emph{Stage\,2}: additionally unfreezes \texttt{denseblock3\,+\,transition3}
at lr=3e-5 with a 3-epoch linear warmup (\texttt{SequentialLR}) to prevent
gradient spikes; same gate (AUC\,$\geq$\,0.752) and revert logic.
Result: public/private AUC \textbf{0.781/0.781} — near-zero pub--priv gap
vs.\ 0.026 for EfficientNet.

%% ── 5. TRAINING OPTIMIZATIONS ────────────────────────────────────
\section{Training Optimizations}

\textbf{Class-imbalance handling.}
\texttt{BCEWithLogitsLoss} with \texttt{pos\_weight}\,$\approx$\,2.76
addresses imbalance at the gradient level. \texttt{WeightedRandomSampler}
oversamples the minority class at the mini-batch level ($+$0.022\,AUC).

\textbf{Test-Time Augmentation (TTA).}
Scores are averaged over four passes: original, horizontal flip, vertical
flip, and 180° rotation (+0.008--0.012\,AUC). Vertical flip is applied at
inference only (not training) to preserve the ImageNet upright prior for
the fine-tuned model.

\textbf{Label Smoothing.}
For the fine-tuned model only ($\varepsilon$=0.05), hard targets become
soft $\{0.025, 0.975\}$, penalising overconfident logits without damaging
the limited training signal~\cite{muller2019label}.

\textbf{Ensemble.}
Grid search over $w\in\{0.10,\ldots,0.30\}$ on validation blends CustomNetV2
and fine-tuned scores for the CUSTOM submission (skipped if custom val
AUC\,$\leq$\,0.62). A consistent val--test gap of $\approx$0.02--0.03 means
gains below $\sim$0.01 on validation should not be over-interpreted.

%% ── 6. ABLATIONS & NEGATIVE RESULTS ─────────────────────────────
\section{Ablations \& Negative Results}

\begin{itemize}
  \item \textbf{CLAHE}: broke \texttt{CropByEye}'s intensity threshold
    ($-$4.6\% custom AUC).
  \item \textbf{Cache pipeline}: fixed 224\,px crops removed per-epoch
    \texttt{RandomCrop} spatial jitter ($-$0.028\,AUC despite 5$\times$ speed-up).
  \item \textbf{Scale jitter (TVRandomResizedCrop)}: no gain ($-$0.004).
  \item \textbf{BenGraham (buggy)}: assumed float [0,1]; \texttt{CropByEye}
    passes uint8 [0,255] — \texttt{clip(uint8,0,1)} collapsed all pixels to
    $\{0,1\}$, producing uniform grey (custom 0.541, ft 0.558). Fixed with
    dtype guard and circular mask: custom private +0.027 (0.743→0.770).
\end{itemize}
